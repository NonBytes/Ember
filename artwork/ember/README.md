# Ember launcher artwork

Generated with the built-in imagegen tool. `ember-source.png` retains the original transparent artwork. `ember-preview.png` previews the legacy icon on the app background.

Android packaging: run `package_icons.py` with Python and Pillow. It fits the artwork into the adaptive safe area and exports mdpi through xxxhdpi PNGs. Background: `#0B0B0E`.

## Generation prompt

Use case: logo-brand. Create a finished Android app icon foreground for an app named Ember, a network/proxy utility with an editorial near-black and flame-orange visual identity. A single distinctive sculptural ember/flame symbol with a subtle flowing E-shaped negative space, bold compact silhouette, luminous vermilion #FF3D1E to warm orange core, restrained dimensional bevels, elegant dark-tech aesthetic. No cat. No letters or words, no typography, no border, no rounded-square tile, no mockup. Actual transparent background. Centered symbol occupying about 65% of the square canvas, generous transparent margin so it fits Android adaptive circle masks. Crisp readable silhouette at 48px; polished original brand mark, minimal internal detail, no particles or detached sparks.
